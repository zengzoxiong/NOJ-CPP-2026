# NOJ C++ 题库归档 2026

西北工业大学 NOJ 平台 C++ 题目全量归档，共 **100** 题，题号 001–100 连续。

## 数据构成

| 路径                   | 说明                  |
| -------------------- | ------------------- |
| `data/problems.json` | 结构化数据，唯一数据源，100 条记录 |
| `problems/NNN-*.md`  | 每题一篇 Markdown，供直接阅读 |
| `data/images/`       | 题目配图，共 62 张         |

## 字段说明

| 字段                             | 含义                              |
| ------------------------------ | ------------------------------- |
| `no`                           | 平台题号，三位字符串                      |
| `title`                        | 题目标题，平台内唯一，可作匹配键                |
| `filename`                     | 平台建议的提交文件名                      |
| `timelimit` / `memorylimit`    | 判题时限与内存上限                       |
| `description`                  | 题目描述正文，保留 LaTeX 公式原文与配图位置       |
| `input` / `output`             | 输入输出格式要求                        |
| `sampleinput` / `sampleoutput` | 样例数据                            |
| `hint`                         | 提示，本题库全部为空                      |
| `source`                       | 题目来源或参考资料链接                     |
| `images`                       | 配图文件名，对应 `data/images/`         |
| `testcases`                    | 测试点数据（组数、输入、期望输出），未探测的题为 `null` |

JSON 保留全部原始字段供程序使用；`problems/` 下的 Markdown 按平台原生版式展示，正文呈现标题、时限内存、Description、Input、Output、Sample Input、Sample Output 七项，末尾以两条 `---` 分隔，其下为测试点章节。

## 测试点

每题 Markdown 末尾以两条 `---` 与正文完全分隔，其下为测试点章节，格式固定为 `## 测试点` / `### 测试点N` / `输入` / `输出` 四项。

**100 题全部完成测试点还原**，共 259 组数据，每组均经平台纯打表程序实际判题 AC 验证（`solve/` 目录 100 个程序）。

| 项 | 说明 |
| --- | --- |
| 已还原题数 | 100 / 100 |
| 单题组数范围 | 1 ~ 5 组 |
| 还原方式 | 时间通道逐字节 dump + 逐行 memcmp 定位 + 参考题解计算输出 |
| 特殊题 | 050 完美矩阵点3 为 297×294 矩阵（174,940 字节），体量过大未逐字节还原，仅记录行列数，其解答由正方形算法兜底 |
