# 065 有效表达式

> 提交文件名：`T065.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

一个有效的表达式由一对小括号“()”包围，“()”可以嵌套（例如“((()))”）、连接（例如“()()()”）或者两种兼有（例如“(())()”）。现在有n对小括号，计算它们可以组成有效的表达式的个数。

## 输入

在一行里输入正整数n。

## 输出

输出计算结果。

## 样例

**输入**

```
6
```

**输出**

```
132
```
