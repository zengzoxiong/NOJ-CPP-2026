# 014 分数的加、减、乘、除法

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

输入两个分数，计算它们的加、减、乘、除。

## Input

输入为2行，每行分别是分数的分子和分母，采用分数形式（参考输入样例）。输入的数据保证运算结果合理。

## Output

输出为4行，分别是两个分数的加、减、乘、除式子和结果，用最简分数形式表示。

## Sample Input

```
2/3
3/7
```

## Sample Output

```
(2/3)+(3/7)=23/21
(2/3)-(3/7)=5/21
(2/3)*(3/7)=2/7
(2/3)/(3/7)=14/9
```
