# 094 【考试题型：分支选择】马赫数

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

马赫数定义为：$M={\nu \over c}$，其中$M$是马赫数，为无量纲量，$\nu$是飞行速度，$c$是飞行器所在位置的音速（单位m/s）。声音在不同的介质中以不同的速度传播，如果知道空气温度（单位$^\circ C$），可以由声速公式给出：$c=331.3\sqrt{1+{T \over 273.15}}$。飞行的马赫数可分为如下四类：
（1）亚音速（subsonic）：小于0.8
（2）跨音速（transonic）：0.8~1.2
（3）超音速（supersonic）：1.2~5.0
（4）高超音速（hypersonic）：5.0~10.0
在跨音速时，飞机周围的局部气压下降，气温也会下降，如果温度低于饱和温度，就会形成凝结水云，不断堆积形成圆锥般的云雾，这种现象称为蒸汽锥（Vapor cone）或激波项圈（Shock collar）。下面是歼20的飞行视频。

> 视频 `MachJ20ZHUHAIAIRSHOW.mp4`：平台服务器未提供该文件，此处仅保留引用名。

## Input

在一行里输入速度V（单位km/h）、温度T，用空格间隔。输入数据保证有意义。根据飞行器高度，可以查表得出温度T。
样例的实际情况是C919民航飞机巡航速度为920km/h，当巡航高度为10000米，对应温度为-49.90摄氏度，其马赫数为0.853，跨音速。

## Output

输出马赫数和分类英文单词（全是小写），马赫数小数点保留3位，用一个空格间隔。

## Sample Input

```
920 -49.90
```

## Sample Output

```
0.853 transonic
```
