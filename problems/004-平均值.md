# 004 平均值

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

编写一个程序，输出整数A、B的平均值。

## Input

在一行中输入整型A和B，用空格间隔。

## Output

输出整数A、B的整型平均值。

## Sample Input

```
3 4
```

## Sample Output

```
3
```
