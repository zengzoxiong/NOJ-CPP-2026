# 048 【专业融合：管理】航空旅行

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

Miku有3个行李，分别重A、B和C公斤，他都想带上飞机。这些行李的其中两个办理登机托运，并随身携带剩下的一个。根据航空公司的规定，托运行李的总重量不能超过D公斤，携带行李的重量不能超过E公斤。看看Miku能不能把所有的三个行李都带上飞机。

## Input

输入第一行为T，表示测试用例数。接下来T行是测试数据，每行包含五个空格间隔的整数A、B、C、D、E。
$`1 \leqslant T \leqslant 36000`$。

## Output

对于每个测试用例，如果可以把所有三个行李都带走，输出“YES”，否则输出“NO”。注意都是大写。

## Sample Input

```
3
1 1 1 15 5
8 7 6 15 5
8 5 7 15 6
```

## Sample Output

```
YES
NO
YES
```
