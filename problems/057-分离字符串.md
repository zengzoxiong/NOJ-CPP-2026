# 057 分离字符串

> 提交文件名：`T057.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

编写一个函数int str_split(string sarr[], string str, string sep);以sep字符串为间隔，分离str字符串为多个部分，并存入到字符串数组中，函数返回分离出来的部分的数目。注意：分离出来的各个部分字符串长度不会大于100，分离出来的部分的数目不会多于20。如果str没有sep，则整个str作为唯一分离出来的部分。

## 输入

在第一行里输入字符串str，第二行输入字符串sep。str和sep字符串可包含空格，sep可以是多个字符。

## 输出

顺序输出分离出来的字符串，每行一个。

## 样例

**输入**

```
www.nwpu.edu.cn
.（小数点）
```

**输出**

```
www
nwpu
edu
cn
```
