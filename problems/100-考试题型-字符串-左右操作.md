# 100 【考试题型：字符串】左右操作

> 提交文件名：`T100.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

已知一个字符串，长度不超过1000个字符。对它的左半部分由大到小排序，对它的右半部分前后对调，如果它的长度是奇数个，则中间的字符不动。
例如字符串“abcdef181292”，处理后为“fedcba292181”。
例如字符串“abcdefX181292”，处理后为“fedcbaX292181”。

## 输入

输入一个字符串。

## 输出

输出处理后的字符串。

## 样例

**输入**

```
abcdefX181292
```

**输出**

```
fedcbaX292181
```
