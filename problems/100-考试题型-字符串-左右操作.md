# 100 【考试题型：字符串】左右操作

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

已知一个字符串，长度不超过1000个字符。对它的左半部分由大到小排序，对它的右半部分前后对调，如果它的长度是奇数个，则中间的字符不动。
例如字符串“abcdef181292”，处理后为“fedcba292181”。
例如字符串“abcdefX181292”，处理后为“fedcbaX292181”。

## Input

输入一个字符串。

## Output

输出处理后的字符串。

## Sample Input

```
abcdefX181292
```

## Sample Output

```
fedcbaX292181
```
