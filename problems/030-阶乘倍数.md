# 030 阶乘倍数

> 提交文件名：`T030.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

已知K是一个大于或等于2的整数，求最小正整数N，使得N！是K的倍数。在问题约束条件下，可以证明这样的N总是存在的。

## 输入

输入K。

## 输出

输出N。

## 样例

**输入**

```
30
```

**输出**

```
5
```
