# 030 阶乘倍数

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

已知K是一个大于或等于2的整数，求最小正整数N，使得N！是K的倍数。在问题约束条件下，可以证明这样的N总是存在的。

## Input

输入K。

## Output

输出N。

## Sample Input

```
30
```

## Sample Output

```
5
```
