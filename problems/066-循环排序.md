# 066 循环排序

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

查阅互联网，循环排序（[Cycle sort](https://en.wikipedia.org/wiki/Cycle_sort)）是一种原地的排序算法，所谓“原地”就是它实现了最小的元素移动次数。当写入成本昂贵时，例如使用EEPROM闪存，每次写入都会缩短存储器的使用寿命，则最小化写入次数非常有用。
Cycle Sort的原理是通过不断地将每个元素放到它应该在的位置上来完成排序。算法步骤如下：

1. （1）从数组的第一个元素开始，将当前元素记为item。
2. （2）初始化一个变量pos，表示item应该在的位置，初始值为0。
3. （3）遍历数组，对于每个元素curr，如果curr小于item，则将pos加1。
4. （4）如果pos没有变化，表示item已经在正确的位置上，跳过后续步骤。否则，将item与pos位置的元素交换，并将pos位置的元素记为curr。
5. （5）重复步骤3和4，直到item回到起始位置。
6. （6）对下一个未排序的元素重复步骤1至5，直到数组排序完成。

## Input

在第一行里输入整数n，在第二行输入n个整数，用空格间隔。

## Output

输出排序结果。

## Sample Input

```
8
1 8 3 9 10 10 2 4
```

## Sample Output

```
1 2 3 4 8 9 10 10
```
