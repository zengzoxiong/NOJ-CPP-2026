# 006 浮点数输出

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

输出一个浮点数的3个格式结果。

## Input

输入一个浮点数。

## Output

输出1行，第1个小数点保留6位，第2个小数点保留2位，第3个小数点保留8位，用逗号作为间隔。

## Sample Input

```
12345567.891234567
```

## Sample Output

```
12345567.891235,12345567.89,12345567.89123457
```

---
---

## 测试点

### 测试点 1

输入：

```
12345567.891234567
```

输出：

```
12345567.891235,12345567.89,12345567.89123457
```

### 测试点 2

输入：

```
123
```

输出：

```
123.000000,123.00,123.00000000
```

### 测试点 3

输入：

```
0.00123
```

输出：

```
0.001230,0.00,0.00123000
```
