# 006 浮点数输出

> 提交文件名：`T006.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

输出一个浮点数的3个格式结果。

## 输入

输入一个浮点数。

## 输出

输出1行，第1个小数点保留6位，第2个小数点保留2位，第3个小数点保留8位，用逗号作为间隔。

## 样例

**输入**

```
12345567.891234567
```

**输出**

```
12345567.891235,12345567.89,12345567.89123457
```
