# 034 幂函数【C++】

> 提交文件名：`T034.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

编写一个默认参数函数：
double pow(double base, int exp=2);
计算base的exp次幂。

## 输入

在一行里输入两个数base、exp，用空格间隔。

## 输出

第一行输出调用pow(base)的结果。
第二行输出调用pow(base,exp)的结果。

## 样例

**输入**

```
1.23 5
```

**输出**

```
1.512900
2.815306
```
