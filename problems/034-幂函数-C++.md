# 034 幂函数【C++】

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

编写一个默认参数函数：
double pow(double base, int exp=2);
计算base的exp次幂。

## Input

在一行里输入两个数base、exp，用空格间隔。

## Output

第一行输出调用pow(base)的结果。
第二行输出调用pow(base,exp)的结果。

## Sample Input

```
1.23 5
```

## Sample Output

```
1.512900
2.815306
```
