# 097 【考试题型：算法策略（递推分治贪心动态规划）】零钞

> 提交文件名：`T097.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

有1元、2元、5元、10元纸币若干，已知顾客购买商品付钱后，需要找零钞n元，求如何找钱，使得用到的纸币最少。

## 输入

在一行里输入n，假定所有数据都是整数。

## 输出

按样例格式输出找钱方案，形式为“零钞=数目”。

## 样例

**输入**

```
25
```

**输出**

```
5=1
10=2
```
