# 097 【考试题型：算法策略（递推分治贪心动态规划）】零钞

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

有1元、2元、5元、10元纸币若干，已知顾客购买商品付钱后，需要找零钞n元，求如何找钱，使得用到的纸币最少。

## Input

在一行里输入n，假定所有数据都是整数。

## Output

按样例格式输出找钱方案，形式为“零钞=数目”。

## Sample Input

```
25
```

## Sample Output

```
5=1
10=2
```
