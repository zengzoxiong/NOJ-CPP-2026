# 084 【算法策略：动态规划】上楼梯

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

一个楼梯有$`N`$阶，一次可以上一个或两个台阶。但是有一些台阶$`a_{1-th}、a_{2-th}、\cdots a_{M-th}`$是坏的，问上到第$`N`$个台阶的方法有多少种？注意：$`1 \leqslant N \leqslant 10^5`$，$`0 \leqslant M \leqslant N-1`$，$`1 \leqslant a_1<a_2< \cdots < a_M \leqslant N-1`$。
（1）对于样例，3台阶是坏的，步骤如下
0→1→2→4→5→6
0→1→2→4→6
0→2→4→5→6
0→2→4→6
共4种
（2）如果输入
10 2
4
5
由于第4、5台阶是坏的，无论如何都上不了，因此输出0

## Input

在第一行里输入$`N`$、$`M`$，用空格间隔。接下来的$`M`$行，每行输入$`a_1、a_2、\cdots a_M`$。

## Output

输出方法数。记住要在每次计算的时候，方法数 mod 1000000007，避免溢出。

## Sample Input

```
6 1
3
```

## Sample Output

```
4
```
