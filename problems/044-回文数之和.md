# 044 回文数之和

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

回文数是指从左向右、从右向左读都相同的数，例如121。一个十进制整数和它的k进制数（2≤k≤8）都是回文数称为双基回文数，例如585和它的二进制数1001001001。
求所有小于n且十进制数和k进制数均是双基回文数的累加和。

## Input

在一行里输入n、k，用空格间隔。输入数据保证有意义。

## Output

输出双基回文数的累加和。例如n=100，k=2时，双基回文数的累加和=1+3+5+7+9+33+99=157。

## Sample Input

```
100 2
```

## Sample Output

```
157
```
