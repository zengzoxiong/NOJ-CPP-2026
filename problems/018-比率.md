# 018 比率

> 提交文件名：`T018.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

编写一个程序将浮点数转换为比率。

## 输入

输入一个浮点数。

## 输出

输出它对应的比率（按最简分数形式）。

## 样例

**输入**

```
4.2
```

**输出**

```
21/5
```
