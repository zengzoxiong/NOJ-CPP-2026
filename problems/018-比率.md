# 018 比率

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

编写一个程序将浮点数转换为比率。

## Input

输入一个浮点数。

## Output

输出它对应的比率（按最简分数形式）。

## Sample Input

```
4.2
```

## Sample Output

```
21/5
```

---
