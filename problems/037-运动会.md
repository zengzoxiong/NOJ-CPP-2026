# 037 运动会

> 提交文件名：`T037.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

学校运动会即将开始，ACM基地组成了一个N×N的仪仗队方阵。为了保证队伍在行进中整齐划一，队长会跟在仪仗队的左后方，根据其视线所及的学生人数来判断队伍是否整齐，如下图所示。

![8001040009.jpg](../data/images/8001040009.jpg)

## 输入

输入整数N（1≤N≤40000）。

## 输出

输出队长在N×N的方阵中看到的人数。

## 样例

**输入**

```
4
```

**输出**

```
9
```
