# 059 字符串后缀

> 提交文件名：`T059.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

编写一个函数int str_endswith(string str, string suffix);，在字符串str中查找是否存在后缀字符串suffix，若存在返回非0（真），否则返回0（假）。例如当str是“hello world!”时
（1）suffix为“world!”为真
（2）suffix为“world”为假
（3）suffix为“!”为真
（4）suffix为“!  ”为假

## 输入

第一行输入字符串str，第二行输入suffix。str和suffix字符串可包含空格。

## 输出

如果str的后缀是suffix，输出“Yes”，否则输出 “No”。

## 样例

**输入**

```
hello world!
world!
```

**输出**

```
Yes
```
