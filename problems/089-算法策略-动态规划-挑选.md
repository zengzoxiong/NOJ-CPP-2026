# 089 【算法策略：动态规划】挑选

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

一个由$`n`$个整数组成的序列$`a`$，可以选择其中的一个元素（令为$`a_k`$）删除它，而且所有等于$`a_k +1`$的元素和$`a_k -1`$的元素也必须从序列中删除，这样的步骤可以执行多次。令sum是$`a_k`$的累加和，求sum的最大值。
例如系列“1 2 3”如果删除1则2会删除，留下3继续删除，故$`sum=1+3=4`$；如果删除3则2会删除，留下1继续删除，故$`sum=3+1=4`$；如果删除2则1、3会删除，故$`sum=2`$。综上，sum的最大值为4。

## Input

在第一行里输入n，在第二行输入n个整数，用空格间隔。

## Output

输出sum的最大值。

## Sample Input

```
3
1 2 3
```

## Sample Output

```
4
```
