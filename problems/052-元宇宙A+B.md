# 052 元宇宙A+B

> 提交文件名：`T052.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

元宇宙（Metaverse）是人类运用数字技术构建的，由现实世界映射或超越现实世界、可与现实世界交互的虚拟世界，具备新型社会体系的数字生活空间。
在我们的现实世界中，使用十进制数。在元宇宙虚拟世界中，使用三十六进制，它有36个数字，即0到9，然后是A到Z（字母使用大写），其中0最小，Z最大。下面是元宇宙虚拟世界的加法示例。
（1）ABC+1=ABD
（2）ZZ+321=420
（3）ZZZ+ ZZZ =1ZZY

## 输入

在一行里输入2个元宇宙整数A、B（每个数至多10位），用空格间隔。输入数据保证有意义。

## 输出

输出A+B的结果。

## 样例

**输入**

```
ZZ 321
```

**输出**

```
420
```
