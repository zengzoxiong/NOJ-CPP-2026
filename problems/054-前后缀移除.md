# 054 前后缀移除

> 提交文件名：`T054.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

编写三个函数，如下：
void str_lstrip(string &str, string chars);
void str_rstrip(string &str, string chars);
void str_strip(string &str, string chars);
分别从str左边（str_lstrip函数）、右边（str_rstrip函数）、两边（str_strip）删除chars里的每个字符。
注意：三个函数将chars里的每个字符逐个删除，str左边、右边或两边可能有多个chars字符需要删除。

## 输入

在第一行里输入字符串str，第二行输入字符串chars。str和chars字符串可包含空格。

## 输出

第一行输出从str左边删除chars里的每个字符的结果。
第二行输出从str右边删除chars里的每个字符的结果。
第三行输出从str两边删除chars里的每个字符的结果。

## 样例

**输入**

```
www.example.com
cmowz.
```

**输出**

```
example.com
www.example
example
```
