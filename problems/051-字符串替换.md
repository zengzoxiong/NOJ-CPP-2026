# 051 字符串替换

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

编写一个函数void str_replace(string &str, string olds, string news);将str字符串中的所有olds子字符串替换成news字符串。注意：str可能因为不包含olds而不会发生实际的替换。

## Input

在第一行里输入字符串str，第二行输入字符串olds，第三行输入字符串news。str、olds和news字符串可包含空格。

## Output

输出替换后的字符串。注意：无论原字符串或是替换后的字符串，字符串长度都不会超过1000。

## Sample Input

```
xxforxx xx for xx
xx
nwpu
```

## Sample Output

```
nwpufornwpu nwpu for nwpu
```
