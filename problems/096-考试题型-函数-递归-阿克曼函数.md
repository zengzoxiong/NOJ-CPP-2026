# 096 【考试题型：函数（递归）】阿克曼函数

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

如下是阿克曼（Ackermann）函数公式：

$$
\begin{aligned}
A(0,n)&=n+1\\
A(m+1,0)&=A(m,1)\\
A(m+1,n+1)&=A(m,A(m+1,n))
\end{aligned}
$$

## Input

在一行里输入两个正整数m、n，用空格间隔。输入数据保证有意义。

## Output

输出阿克曼函数的计算结果。

## Sample Input

```
2 3
```

## Sample Output

```
9
```
