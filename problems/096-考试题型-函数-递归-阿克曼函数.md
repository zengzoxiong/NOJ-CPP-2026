# 096 【考试题型：函数（递归）】阿克曼函数

> 提交文件名：`T096.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

如下是阿克曼（Ackermann）函数公式：
$$
\begin{flalign}
&A(0,n)=n+1 &&\\
&A(m+1,0)=A(m,1) &&\\
&A(m+1,n+1)=A(m,A(m+1,n)) &&\\
\end{flalign}
$$

## 输入

在一行里输入两个正整数m、n，用空格间隔。输入数据保证有意义。

## 输出

输出阿克曼函数的计算结果。

## 样例

**输入**

```
2 3
```

**输出**

```
9
```
