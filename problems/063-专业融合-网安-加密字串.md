# 063 【专业融合：网安】加密字串

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

给定一个字符串s，按以下方式加密该字符串：

1. 如果当前字符出现的频率是偶数，则将当前字符增加x。
2. 如果当前字符的出现频率为奇数，则将当前字符减x。

所有运算都是循环的，即“z”加 1 将得到“a”，而“a”减 1 将得到“z”。

## Input

在第一行里输入字符串s，第二行输入整数x。

## Output

输出加密的结果。例如输入s="abcda", x=3，则结果是dyzad，因为
'a' 在字符串中出现 2 次，因此 'a' 增加 3 变为 'd'
'b' 在字符串中出现 1 次，因此 'b'减少 3 变为 'y'
'c' 在字符串中出现 1 次，因此 'c' 减 少3 变为 'z'
'd' 在字符串中出现 1 次，因此 'd' 减 少3 变为 'a'
'a' 在字符串中出现 2 次，因此 'a' 增加 3 变为 'd'
则结果为"dyzad"

## Sample Input

```
abcda
3
```

## Sample Output

```
dyzad
```
