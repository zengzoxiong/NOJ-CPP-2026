# 056 删除前后缀

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

编写两个函数，如下：
void str_removeprefix(string &str, string prefix);
void str_removesuffix(string &str, string suffix);
分别从str左边（str_removeprefix函数）删除前缀prefix、从右边（str_removesuffix函数）删除后缀suffix。
注意：与strip不一样，两个函数是将prefix、suffix作为整体词语删除的，而不是删除字符，str的前缀后缀可能有多个词语都需要删除。

## Input

在第一行里输入字符串str，第二行输入字符串words。str和words字符串可包含空格。

## Output

第一行输出删除str前缀words的结果。
第二行输出删除str后缀words的结果。

## Sample Input

```
antiantianwartiantianti
anti
```

## Sample Output

```
anwartiantianti
antiantianwarti
```
