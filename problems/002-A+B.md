# 002 A+B

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

编写一个程序，输出A+B的结果。

## Input

在一行中输入整型A和B，用空格间隔。

## Output

输出A+B的值。

## Sample Input

```
3 4
```

## Sample Output

```
7
```

---
---

## 测试点

经黑盒探测确认共 2 个测试点，均为简单整数加法。

共 2 组：

### 测试点 1

输入：

```
3 4
```

期望输出：

```
7
```

说明：正整数相加。

### 测试点 2

输入：

```
-1 -2
```

期望输出：

```
-3
```

说明：负数相加。
