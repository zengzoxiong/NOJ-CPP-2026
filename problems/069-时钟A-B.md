# 069 时钟A-B

> 提交文件名：`T069.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

C语言的time.h头文件（C++是ctime）包含了与时间有关的结构体和功能函数，通过互联网查询它们的细节。已知A和B是两个时间（日期不同，时间相同），计算A-B的结果。

## 输入

在第一行里输入A的日期年、月、日，用空格间隔。
在第二行里输入B的日期年、月、日，用空格间隔。
输入数据保证有意义。

## 输出

输出A-B的结果，结果按秒为单位，可正可负，小数点保留六位。

## 样例

**输入**

```
2021 1 2
2021 1 1
```

**输出**

```
86400.000000
```
