# 079 【专业融合：数学】中位数

> 提交文件名：`T079.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

统计学上，中位数（Median）又称中值，是一个样本、种群或概率分布的数值，其可将数值集合划分为数量相等的上下两部分。对于有限的数集，可以通过把所有观察值高低排序后找出正中间的一个作为中位数。如果观察值有偶数个，则中位数不唯一，通常取最中间的两个数值的平均数作为中位数。
如果数据集有奇数个观测值，则选择中间的一个。例如，七个数字1、3、3、6、7、8、9 的列表，中位数为6。如果数据集有偶数个观测值，则没有明显的中间值，中位数定义为两个中间值的算术平均值。例如，8个数字1, 2, 3, 4, 5, 6, 8, 9 组成的数据集，中值为4.5，即 (4+5)/2。

## 输入

输入的整数有若干个。若输入大于0，将其增加到队列中；若输入为0，将前面形成的队列输出，并输出中位数（小数点保留6位）；若输入小于0，程序终止。数据均用空格间隔。

## 输出

按照要求输出结果。每个数据之间用空格间隔，每次队列输出另起一行，参考样例。

## 样例

**输入**

```
1 2 3 4 5 0
7 8 9 0
-1
```

**输出**

```
1 2 3 4 5 3.000000
1 2 3 4 5 7 8 9 4.500000
```
