# 088 【算法策略：贪心】绝对差

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

绝对差是指两个值之间的差的绝对值，例如$`|a-b|`$或$`|b-a|`$。已知n个元素的数组arr，找出其中任意两个元素绝对差的最小值。

## Input

在第一行里输入n，在第二行输入n个整数为数组元素，用空格间隔。
注意：$`2 \leqslant n \leqslant 10^5`$，$`-10^9 \leqslant arr[i] \leqslant 10^9`$。

## Output

输出最小绝对差。

## Sample Input

```
3
3 -7 0
```

## Sample Output

```
3
```
