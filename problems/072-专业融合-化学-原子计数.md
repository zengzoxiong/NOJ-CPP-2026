# 072 【专业融合：化学】原子计数

> 提交文件名：`T072.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

给定一个字符串形式的化学式子，获取该化学式中的原子数。
原子元素始终以大写字符开头，然后是零个或多个小写字母，代表元素名称。如果原子计数大于1，则后面可能会出现代表该计数的一位或多位数字。如果计数为1，则后面不会有数字。例如“H2O”和“H2O2”是可能的，“H1O2”是不可能的。
两个式子可以连接在一起形成另一个化学式子，例如"H2O2He3Mg4"。

## 输入

输入一个字符串，表示化学式子。输入数据保证有意义。

## 输出

所有元素按名称的ASCII由小到大排序，相同的元素原子计数累计。每行输出一个元素，先是元素名称，后跟其原子计数，用空格间隔，依此类推若干行。

## 样例

**输入**

```
Fe2H3OH
```

**输出**

```
Fe 2
H 4
O 1
```
