# 098 【考试题型：输入输出】气体扩散

> 提交文件名：`T098.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

在相同的温度和压力下，气体的扩散速度与其密度或分子量的平方根成反比，称为格拉罕姆定律（Graham's Law），公式如下：
$$
\begin{flalign}
&{Rate_{1} \over Rate_{2}}=\sqrt{M_{2} \over M_{1}} &&\\
\end{flalign}
$$
这里的$Rate_{1}$和$Rate_{2}$分别是第一种和第二种气体的扩散速度，单位是多少体积或多少摩尔数/单位时间，$M_{1}$和$M_{2}$分别是两种气体的分子量。

可以用气体扩散方法分离同位素：天然的铀元素中只含0.72%的$^{235}U$和99.28%的$^{238}U$，将$^{235}U$和$^{238}U$与氟反应生成$^{235}UF_{6}$和$^{238}UF_{6}$，并加热成气态，然后通过多孔板，尽管$^{235}UF_{6}$的扩散速率仅仅是$^{238}UF_{6}$的1.004倍，但经过多个多孔挡板之后，$^{235}UF_{6}$就会走在最前面，富集之后就是浓缩铀，可用于反应堆（含3%的$^{235}U$）和制造核潜艇的燃料（含20%的$^{235}U$)。
样例反映的正是实际情况：$^{235}UF_{6}$是349.03g/mol，$^{238}UF_{6}$是352.04g/mol，则$^{235}UF_{6}$与$^{238}UF_{6}$的扩散速率比为1.0043。

> 视频 `EffusionandGrahamsLaw.mp4`：平台服务器未提供该文件，此处仅保留引用名。

## 输入

在一行里输入第一种、第二种气体的分子量（单位g/mol），用空格间隔。输入数据保证有意义。

## 输出

输出第一种、第二种气体的扩散速率比，保留四位小数。

## 样例

**输入**

```
349.03 352.04
```

**输出**

```
1.0043
```
