# 083 【算法策略：分治】子数组最大和

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

给定一个整数数组，在所有可能的子数组中找到最大和。

## Input

在第一行里输入数组长度n，在第二行里输入n个整数，用空格间隔。

## Output

求出子数组的最大和。

## Sample Input

```
7
2 -4 1 9 -6 7 -3
```

## Sample Output

```
11
```
