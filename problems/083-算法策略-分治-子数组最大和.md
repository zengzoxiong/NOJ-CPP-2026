# 083 【算法策略：分治】子数组最大和

> 提交文件名：`T083.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

给定一个整数数组，在所有可能的子数组中找到最大和。

## 输入

在第一行里输入数组长度n，在第二行里输入n个整数，用空格间隔。

## 输出

求出子数组的最大和。

## 样例

**输入**

```
7
2 -4 1 9 -6 7 -3
```

**输出**

```
11
```
