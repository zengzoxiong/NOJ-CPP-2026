# 082 【算法策略：动态规划】打字机

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

一台打字机使用年代久远，出现了问题：打印m字母时会打印nn，打印w字母是会打印uu。现在我们收到一张纸条，上面是该打字机打印的信息s，问其原本的字符串有多少种可能性。
例如：
得到“ennkuu”，它原本是4个字符串之一：ennkuu、ennkw、emkuu、emkw。
得到“nwpu”，它原本是1个字符串：nwpu。
得到“nnn”，它原本是3个字符串之一：nnn、nm、mn。

## Input

在一行里输入一个字符串。注意，输入的字符串中应该不会有m和w字母，如果有那说明不是这台打字机打印的字条，此时结果应该输出0。

## Output

输出可能性数目。

## Sample Input

```
ennkuu
```

## Sample Output

```
4
```
