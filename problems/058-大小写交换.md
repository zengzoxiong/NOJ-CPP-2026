# 058 大小写交换

> 提交文件名：`T058.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

编写一个函数string str_swapcase(string str);将str字符串中的所有大写字母转换为小写字母，小写字母转换成大写字母，通过函数返回结果。

## 输入

在一行里输入字符串str。str字符串可包含空格。

## 输出

输出大小写交换以后的字符串。

## 样例

**输入**

```
Hello world
```

**输出**

```
hELLO WORLD
```
