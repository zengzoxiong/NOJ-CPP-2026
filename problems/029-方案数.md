# 029 方案数

> 提交文件名：`T029.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

给定一个数字N，把它展开成连续正整数之和的式子，求有多少种方案。例如N=9时，有9 = 4 + 5 = 2 + 3 + 4三种，其中N自身为一种。

## 输入

输入N。

## 输出

输出方案数。

## 样例

**输入**

```
9
```

**输出**

```
3
```
