# 029 方案数

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

给定一个数字N，把它展开成连续正整数之和的式子，求有多少种方案。例如N=9时，有9 = 4 + 5 = 2 + 3 + 4三种，其中N自身为一种。

## Input

输入N。

## Output

输出方案数。

## Sample Input

```
9
```

## Sample Output

```
3
```
