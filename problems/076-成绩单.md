# 076 成绩单

> 提交文件名：`T076.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

已知一个结构体struct tagStudent {
    char id[11]; //学号
    char name[31]; //姓名
    int score; //成绩
} ST;表示学生成绩单，学号为数字构成的字符串。
输入学生数据，排序输出成绩单：首先按成绩由高到低排序，如果成绩相同，则按学号由小到大排序。

## 输入

在一行里输入整数n（n≤50），在接下来的n行中每行输入学号字符串、姓名字符串、成绩，用空格间隔。

## 输出

输出排序后的成绩单，如样例格式。

## 样例

**输入**

```
6
2001900001 Jerry 88
2001900005 Tom 92
2001900006 Milla 85
2001900002 Alice 80
2001900003 Mickey 85
2001900004 Aladdin 83
```

**输出**

```
2001900005 Tom 92
2001900001 Jerry 88
2001900003 Mickey 85
2001900006 Milla 85
2001900004 Aladdin 83
2001900002 Alice 80
```
