# 085 【算法策略：贪心】三角形

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

给定一组木棒的长度，用它们来构造三角形：
（1）选择三角形周长最大的
（2）如果满足（1）的三角形有多个，选择最大边最长的
（3）如果满足（2）的三角形有多个，选择最小边最长的
（4）如果满足（3）的三角形有多个，输出其中任何一个

## Input

在第一行里输入n，表示数组a的长度。在第二行里输入n个a[i]，用空格间隔，表示各个木棒的长度。
注意：$`3 \leqslant n \leqslant 50`$，$`1 \leqslant a[i] \leqslant 10^9`$。

## Output

输出满足条件的三角形的3个边长，用空格间隔，参考样例。如果没有这样的三角形，输出-1。

## Sample Input

```
6
1 8 5 2 4 3
```

## Sample Output

```
4 5 8
```
