# 095 【考试题型：文件】平方根

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

输入n，将1至n的平方根输出到文件rr.dat中，小数点保留六位，文件中每行一个输出结果。
关闭该文件。然后再次读取该文件，将结果显示出来。

## Input

输入n。

## Output

从文件中读取的数据，逐个显示到屏幕上，用空格间隔，小数点保留六位，参考样例。

## Sample Input

```
5
```

## Sample Output

```
1.000000 1.414214 1.732051 2.000000 2.236068
```
