# 092 【考试题型：数组】重复元素

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

统计一个数组中重复元素的总数。

## Input

在第一行里输入整数n（$`n \leqslant 1000`$），第二行里输入n个整数，用空格间隔。

## Output

输出重复元素的总数。
样例十个数，“1”重复3个，“10”重复1个，“25”重复1个，合计5个。

## Sample Input

```
10
1 10 20 1 25 1 10 30 25 1
```

## Sample Output

```
5
```
