# 017 组合数

> 提交文件名：`T017.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

有a，b，c和d（0≤a，b，c，d ≤9）四个数，求（a + b + c + d）等于n的组合数。

## 输入

输入n，1≤n≤50。

## 输出

输出组合数。

## 样例

**输入**

```
15
```

**输出**

```
592
```
