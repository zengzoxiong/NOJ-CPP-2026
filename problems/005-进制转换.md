# 005 进制转换

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

输入一个非负整数，输出它的十六进制，八进制。

## Input

输入一个非负整数。

## Output

在一行里输出十六进制、八进制，用逗号间隔。十六进制A~F大写。

## Sample Input

```
10
```

## Sample Output

```
A,12
```
