# 099 【考试题型：循环（迭代）】圆周率π

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

作为一个数学常数，π，数千年来数学家们一直试图高精度计算它的值，其计算历经了古代、多边形逼近、无限序列、计算机时代。公元纪年之前π的近似值精确到小数点后两位，到了第一个千年中期，中国数学家精确到小数点后七位，此后直到中世纪晚期才取得进一步进展。微积分的发明很快导致了数百位π的计算，进入20世纪和21世纪，数学家和计算机科学家一直在寻求新的方法，这些方法与不断增长的计算能力相结合，将π的十进制表示扩展到数万亿位数字。下面是π的莱布尼茨公式
$$
\begin{flalign}
&{\pi \over 4}=1-{1 \over 3}+{1 \over 5}-{1 \over 7}+{1 \over 9}-\cdots &&\\
\end{flalign}
$$
它收敛得相当慢，在经过500000项后，只产生了π的五个十进制数字。比它收敛得更快的一个π无穷级数如下：
$$
\begin{flalign}
&{\pi}=3+{4 \over {2 \times 3 \times 4}}-{4 \over {4 \times 5 \times 6}}+{4 \over {6 \times 7 \times 8}}-{4 \over {8 \times 9 \times 10}}+\cdots &&\\
\end{flalign}
$$
它的第1项为3，第2项为3.1666$\cdots$，第2项为3.1333$\cdots$，第4项为3.1452$\cdots$，等等。

## Input

在一行里输入正整数n（$1 \leqslant n \leqslant 10^9$）。

## Output

输出π无穷级数n项时的值，小数点保留七位。

## Sample Input

```
100
```

## Sample Output

```
3.1415929
```
