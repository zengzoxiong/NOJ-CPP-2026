# 019 操作数

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

任意一个整数n，每次操作用n减去它的各位数字之和，直到n小于等于0，统计操作的次数。例如21，$`21-3=18-9=9-9=0`$，所以操作数为3。

## Input

输入正数n。

## Output

输出操作次数。

## Sample Input

```
21
```

## Sample Output

```
3
```
