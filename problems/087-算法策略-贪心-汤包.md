# 087 【算法策略：贪心】汤包

Time Limit: 1000ms , Memory Limit: 10000KB

## Description

有$n$个顾客在景区里的小吃店买汤包，第$i$个订单在$t_i$时刻提出且需要$d_i$时长来完成。求每个顾客得到自己汤包的顺序是怎样的。

## Input

在第一行里输入n，在接下来的n行里输入$t_i$、$d_i$，用空格间隔，表示第$i$个订单提出时刻、完成时长。

## Output

输出得到汤包的顺序。
样例中，3位顾客，第2位顾客1时刻先提出订单，完成时长为3，故在4时刻时得到汤包，第3位顾客2时刻提出订单，完成时长为3，故在5时刻时得到汤包，第1位顾客3时刻提出订单，完成时长为3，故在6时刻时得到汤包。则输出结果为2 3 1。

## Sample Input

```
3
3 3
1 3
2 3
```

## Sample Output

```
2 3 1
```
