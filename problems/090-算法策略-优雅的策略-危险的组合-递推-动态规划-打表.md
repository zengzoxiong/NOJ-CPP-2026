# 090 【算法策略：优雅的策略】危险的组合（递推、动态规划、打表）

> 提交文件名：`T090.cpp` ｜ 时限 1000ms ｜ 内存 10000KB

## 题目描述

有一些装有铀（用U表示）和铅（用L表示）的盒子，数量均有无限多个。要求把$n(n \leqslant 30)$个盒子放成一行，若出现了3个或更多铀放在一起的情形，例如$\cdots LUUU、\cdots UUUL、\cdots UUU \cdots$等，称它是一种“危险的组合”。求有多少种这样的危险组合？
例如：对于只有1、2个盒子时，不会构成“危险的组合”，3个盒子时，UUU构成1种“危险的组合”，4个盒子时，UUUL、LUUU、UUUU构成3种“危险的组合”，依次类推。

## 输入

输入若干行测试用例整数n（n≤30），直到输入≤0结束或者没有数据结束。
在CodeBlocks、Dev-C++等工具调试运行时，输入Ctrl+Z会产生“没有数据”。

## 输出

针对每个测试用例n，输出危险组合数。

## 样例

**输入**

```
1
2
3
4
5
0
```

**输出**

```
0
0
1
3
8
```
